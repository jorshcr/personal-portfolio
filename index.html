FPGA Camera Vision Accelerator

VerilogFPGADigital DesignClock-Domain CrossingBRAMImage Processing

Hardware acceleration of OpenCV's ORB algorithm on Nexys A7-100T running at 1 pixel/clock @ 100 MHz; streaming live from OV7670 camera module to VGA output.

Read more...Show less

Problem / Inspiration: Primarily, I pursued this project because I wanted to introduce myself to hardware acceleration and I had an FPGA provided for my EE354 class.

Contributions: I first built out OV7670 Camera capture module with async FIFO for clock-domain crossing (25 MHz, 100 MHz). Added BRAM frame-buffering for VGA output and also ORB. Then I built Sobel Edge Filtering with 3x3 window. Then pipelines for FAST-9 corner detection and ORB descriptors alongside partner. Ran testbenches and simulations for individual module verification.

Results / Outcomes: Produced 640 Ã— 480 VGA output with switchable modes: raw grayscale, sobel edge filtering, and FAST keypoints. Closed timing at 100 MHz. Design supports up to 384 ORB keypoints per frame. Next steps are integrating ORB output with CPU processing.

UNIT Fitness

Embedded SystemsBLEIMULoad CellsSignal Processing

A retrofit sensor system for weight-stack machines that sends workout data to an iOS app. It explores automatic rep, set, and effort tracking without manual logging.

Read more...Show less

Problem / Inspiration: Track repetitions, sets, and effort on weight-stack machines without manual logging.

Contributions: The system streams IMU and HX711 load-cell data over BLE. Real-time motion segmentation isolates concentric movement, while a regression model trained on more than 50 lat-pulldown sets estimates proximity to muscular failure.

Results / Outcomes: Developed the sensor-to-app tracking system and an effort-estimation model trained on more than 50 lat-pulldown sets.
