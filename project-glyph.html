Glyph Robotics Demo

ROS 2, Nav2, Systems Integration

An autonomous drink-dispensing system mounted on a quadruped robot. It combines mobile ordering, navigation, and a playful LED fluid display into one demonstration.

Expanded project description below

Problem / Inspiration: Create an autonomous drink-delivery demonstration for USC Terra Labs demo day.

Contributions: Led a five-person team at USC Terra Labs to build the Unitree Go2-based demo. The system integrates Nav2 path planning, three soda flavors, a mobile ordering interface, and a real-time fluid simulation on LED matrices.

Outcomes: Delivered the club demonstration, combining robot navigation, drink dispensing, mobile ordering, and LED visualization.
