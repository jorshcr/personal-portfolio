Scrambler Humanoid Robot

JAX, Reinforcement Learning, MuJoCo

A reinforcement-learning pipeline exploring how a humanoid robot could balance and crawl on steep terrain. The project combines simulated locomotion with a vision-based approach to evaluating grip.

Expanded project description below

Problem / Inspiration: Explore humanoid balancing and crawling for steep-terrain locomotion.

Contributions: Developed a two-stage PPO pipeline for the 29-DOF Unitree G1, targeting slopes of 30–45 degrees in simulation. An ArUco-based vision pipeline tracks compliant-hand deformation to estimate grip quality. The project placed second at Himalaya Hacks; these are development targets, not measured physical deployment results.

Outcomes: Placed second at Himalaya Hacks. The locomotion pipeline targeted 30–45° slopes; physical performance results are not established.
