FPGA Camera Vision Accelerator

VerilogFPGADigital DesignClock-Domain CrossingBRAMImage Processing

A real-time camera system that displays edge detection and feature overlays on a VGA monitor. It brings image processing directly into hardware, with pipelines designed to process one pixel per clock.

Read more...Show less

Problem / Inspiration: Process live camera images directly on an FPGA, including edge and feature detection.

Contributions: Built on the Nexys A7-100T with an OV7670 camera, asynchronous clock-domain crossing, and BRAM frame buffering. The design supports Sobel filtering, FAST-9 corner detection, and ORB descriptors, with timing closed at 100 MHz.

Results / Outcomes: Produced 640 × 480 VGA output and closed timing at 100 MHz. The design supports up to 384 ORB keypoints per frame.

Scrambler Humanoid Robot

JAXMuJoCoReinforcement LearningPPOComputer Vision

A reinforcement-learning pipeline exploring how a humanoid robot could balance and crawl on steep terrain. The project combines simulated locomotion with a vision-based approach to evaluating grip.

Read more...Show less

Problem / Inspiration: Explore humanoid balancing and crawling for steep-terrain locomotion.

Contributions: Developed a two-stage PPO pipeline for the 29-DOF Unitree G1, targeting slopes of 30–45 degrees in simulation. An ArUco-based vision pipeline tracks compliant-hand deformation to estimate grip quality. The project placed second at Himalaya Hacks; these are development targets, not measured physical deployment results.

Results / Outcomes: Placed second at Himalaya Hacks. The locomotion pipeline targeted 30–45° slopes; physical performance results are not established.

UNIT Fitness

Embedded SystemsBLEIMULoad CellsSignal Processing

A retrofit sensor system for weight-stack machines that sends workout data to an iOS app. It explores automatic rep, set, and effort tracking without manual logging.

Read more...Show less

Problem / Inspiration: Track repetitions, sets, and effort on weight-stack machines without manual logging.

Contributions: The system streams IMU and HX711 load-cell data over BLE. Real-time motion segmentation isolates concentric movement, while a regression model trained on more than 50 lat-pulldown sets estimates proximity to muscular failure.

Results / Outcomes: Developed the sensor-to-app tracking system and an effort-estimation model trained on more than 50 lat-pulldown sets.
