Star Wars Hand Scanner

Mechatronics, Capacitive Sensing, Electrical Design

A touch-reactive hand scanner built for a public Star Wars exhibit. The installation synchronizes sensing, lights, and motion to create a reliable visitor interaction.

Expanded project description below

Problem / Inspiration: Create a responsive, reliable interaction for visitors entering a public Star Wars exhibit.

Contributions: Served as electrical lead for the installation at the Ronald Reagan Presidential Library. The system combines capacitive touch sensors, stepper-driven linear actuation, and LEDs, with eight-hour uptime reported in the experience record.

Outcomes: Deployed at the Ronald Reagan Presidential Library, with eight-hour uptime reported in the experience record.
